# Documentation rules

- Separate the verified facts, the inferences, the assumptions, the estimates and the proposals, and label each one.
- Every changeable external claim gets a URL, an access date, a publication date if known, and a confidence rating H/M/L. The raw evidence goes in `docs/production-plan/research/`.
- Keep the software licence separate from the data rights.
- Never include credentials, key prefixes, local absolute paths or personal data. The repository is public.
- Keep cross-links relative and check them. Durable decisions go in `docs/production-plan/adr/ADR-NNN-*.md`.
